# ADR-0010：下载线路策略——自动有裕度，强制单线只对核心文件严格

- 状态：已采纳（含防线测试）
- 日期：2026-11-13
- 关联：第 42 轮（启动探测自动切换）、第 70–71 轮（线路塌缩事故）、第 74 轮（下载日志/补丁）、第 85 轮（本 ADR）

## 背景

第 42 轮起的 "下载源" 只有两个值（官方 / BMCLAPI）。它是"指定一条线路"：
- 用户在设置里看到的 BMCLAPI，**往往是探测自动写进去的**，不是他自己点的；
- 一旦写进配置就永久固定，"哪条快用哪条"只发生在元数据请求的竞速里，二进制下载（client.jar、库、资源）完全按这个固定值走；
- 第 70 轮的事故正是这条线：一次自动切换 + 一个废弃域名 = 版本列表空白。

## 决定

### 1. 三态策略，默认 Auto

`DownloadPolicy { Auto, Official, Mirror }`，配置键 `routePolicy`。
Auto = 两条线路都在集合里，按测速结果排序，失败跨线路重试一次。

### 2. 判定规则纯逻辑、有裕度

`DownloadRoutePolicy.Decide(officialMs, mirrorMs, fallback)`：
- 一方不可达（null 或 >3000 ms）→ 另一方；
- 都可达 → 快的一方，但要求至少快 40 ms，否则维持上次的选择（避免 240/250 ms 反复横跳）；
- 都不可达 → `fallback`（不猜）。

3000 ms 这个阈值来自实际体验：4 秒才响应的主机在"点一下就等"的流程里等于失败。

### 3. 强制模式：核心文件严格执行，非核心允许静默回退

`IsCoreAsset(url)`（jar / libraries / versions / indexes / version_manifest）= 缺了就起不来。
- 强制官方 + 核心文件失败 → **报错**，不偷偷走镜像（用户明确排除了它）；
- 强制官方 + 贴图/音效失败 → 静默走镜像并记日志（不能因为一张图让整个安装失败）。

### 4. 测速：HEAD、缓存、单飞、绝不进下载路径

- HEAD 优先；对方 405/501 时退化为 `Range: bytes=0-0`（1 字节），绝不下载整个清单。
- 结果缓存 5 分钟，并发调用共享同一个 in-flight 任务。
- 下载路径只读 `NetworkProbe.Preference`（静态字段），没有 await、没有 IO —— 这是"每次下载先测速 10 秒"这一类问题的结构性防线。

### 5. 老配置统一迁成 Auto

`downloadSource` 的 0/1 都迁 `Auto`。理由：那个值经常是探测写的；按 1→Mirror 迁移等于把"只能走一条"固化。需要强制镜像的人在设置里选一次即可（三个选项就在那里）。

## 后果

- 好：不必再猜"该选哪条"；探测结果只影响顺序，不影响可用性（两条都在）；官方被墙时自动回退，不浪费 5 次重试。
- 代价：Auto 模式下每个文件都可能多一次跨线路重试（只在首条线路失败时发生，且只一次）。
- 已知限制：`/maven/…` 这类共有前缀无法可靠反解到官方（第 71 轮的 `ToOfficialUrl` 故意不猜），所以这类 URL 的"官方↔镜像"互转可能返回 null —— 表现是不换线而是重试，不会误打到别的 maven。

## 防线（测试，不是注释）

1. 判定矩阵：100/500、500/100、null、4000 ms、40 ms 裕度、双死；
2. 路由集合：强制官方/镜像各只有一条；自动按优先级两条；非 MoJang URL 不臆造镜像且不返回空集合；
3. `IsCoreAsset` 分类；
4. 源码扫描：`NetworkProbe` 必须 HEAD、不得出现 `GetByteArrayAsync`、必须 5 分钟缓存与单飞；`NetRouting` 不得 `await NetworkProbe.`；`DownloadEngine` 不得引用测速、必须存在 `switchedRoute` 且只换一次；
5. `AlternateRouteUrl` 官方↔镜像互转、第三方返回 null；强制官方时核心文件 `RouteSwitchAllowed == false`。

## 反例（如果不这么做）

- 若强制官方仍然静默走镜像：用户"排除镜像"的意图被无视，且日志里看不出数据来自哪里。
- 若测速放在下载循环里：每个文件多一次 RTT，安装 3888 个资源时足以让人以为程序卡死。
- 若没有 40 ms 裕度：每次启动都可能在 240/250 ms 之间换线，用户看到的"当前优先"一直在跳。
