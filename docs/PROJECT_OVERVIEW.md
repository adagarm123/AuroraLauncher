## 安全与合规要点

- **密钥处理**：微软刷新令牌使用 Windows DPAPI（`CryptProtectData` P/Invoke）加密后落盘；访问令牌仅驻留内存、永不写入磁盘。配置中不含任何密钥。
- **TLS**：HTTP 客户端**永不**禁用证书校验。
- **用户数据保护**：实例删除仅在 `instances/` 目录内进行；导入一律**复制**，不触碰源数据。
- **下载源**：默认官方 Mojang/Microsoft；BMCLAPI 镜像由**网络感知自动切换**（用户显式选择永远优先），URL 重写仅作用于已知域名。
- **诊断包隐私**：所有打包文本统一过正则脱敏（token/device_code/Bearer/代理凭据/用户路径，**替换非删除**，保留字段结构），附**脱敏报告**逐文件列明替换处数；日志仅保留末尾 2MB。
- **合规**：见 `LICENSE` —— 未使用 PCL2/HMCL 源码，独立实现；ADR 中有合规决策记录。

## 已知限制

1. **微软登录**：Azure 不允许启动器替用户注册应用，需自备 Client ID（一次性四步配置，**设置页可直接填入**或用环境变量 `AURORA_MICROSOFT_CLIENT_ID`）；未配置时点击登录会显示完整指引而非裸报错。
2. **加载器安装**：Forge/NeoForge 官方安装器需要本机 **Java 21+**（启动器会自动探测；缺 Java 时可在 设置 → Java 环境 一键安装）且对应 Maven 仓库可达。
3. **OptiFine**：已支持一键唤起官方安装器；安装器无静默参数，最后一步需用户点 Install，且需手动导入生成的新版本。
4. **CurseForge**：已支持站内搜索/浏览；平台不向第三方开放多数文件的直接下载，需跳官方网页完成后本地导入。
5. **BMCLAPI**：作为自动回退/感知源，遵循其服务条款。
